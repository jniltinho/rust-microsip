# Development skills

Installed locally on 2026-10-12 at the user's request. Files are in `.agents/skills/`, with relative links in `.claude/skills/`. `skills-lock.json` records installer-provided origins and hashes. These are not runtime/build dependencies of the future application.

| Skill | Source | Use in this proposal |
|---|---|---|
| rust-best-practices | https://github.com/apollographql/skills/tree/main/skills/rust-best-practices | Ownership, typed errors, clippy, rustdoc, and API separation |
| rust-async-patterns | https://github.com/wshobson/agents/tree/main/plugins/systems-programming/skills/rust-async-patterns | Tokio separate from UI, bounded channels, cancellation, and shutdown |
| rust-testing | https://github.com/affaan-m/ecc/tree/main/skills/rust-testing | TDD, unit/integration/property tests |
| openspec-* | https://github.com/Fission-AI/OpenSpec | Proposal, specs, design, and tasks; generated by OpenSpec 1.10.0 |

General repository instructions take precedence. Do not mechanically copy skill examples: this project will not adopt production `unwrap()`, unbounded tasks, or blocking audio callbacks. Library suggestions require license auditing and technical validation during implementation.

REA (https://github.com/morluto/rea) was consulted but **not installed**: available code analysis and graph MCP were sufficient at this stage. Conditional user authorization does not require unnecessary changes to global Grok, Claude, or Codex settings.

MIT texts for the three Rust skills are alongside each skill. References were normalized only for trailing whitespace; the lock retains hashes of the upstream distribution captured by the installer.
