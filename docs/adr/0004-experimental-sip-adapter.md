# ADR 0004 — experimental G0 signaling adapter

Date: 2026-10-12. Status: accepted for isolated G0 evaluation only; all full G0/release gates remain open. Baseline: `8fb57a2`.

Use rsipstack 0.7.3 behind `crates/telephony/`, with pinned registry/checksum identity, `default-features=false`, `platform-tokio,rustls`. Use rustls 0.23.45 with ring 0.17.14 and explicit CA/hostname validation, never a custom verifier. Tokio 1.53.2 / tokio-util 0.7.20, thiserror 2.0.21, secrecy 0.10.3 and zeroize 1.9.1 use the licensing paths in [ADR 0003](0003-g0-license-and-native-boundaries.md). The lab example additionally uses libc 0.2.190 (MIT OR Apache-2.0) for safe O_NOFOLLOW/O_CLOEXEC constants, not unsafe FFI. Their exact graph/notices accompany the Docker export. Registry source/checksums and selected-feature checks precede use; a candidate's claimed features do not establish interoperability.

Start with an explicit synthetic registration probe (register, refresh, unregister) plus wrong-password and TLS-negative tests in the isolated PBX. It is not the final configuration resolver, renewal/backoff actor or shipping control CLI. The ordinary scaffold must not register or read account files. The lab-only Rust example reads only its explicitly mounted fictional directory; no password arguments, personal HOME, production calls, or microphones.

Select the kernel route's concrete local IP before binding, check the transport's actual local socket, and inspect outgoing REGISTER Contact/Call-ID/CSeq with bounded private state. Success requires the expected concrete Contact, a stable Call-ID and strictly advancing CSeq at each completed phase (equal CSeq is permitted only for retransmissions within a phase). Emit booleans only, not identifiers/addresses/headers. The Rust overlay disables PBX Contact rewriting for this internal-only proof; default/host fixtures retain their original policy. This proves one explicit refresh cycle, not scheduled renewal/NAT behavior. The runner is a local lab artifact, not an attested release image.

Own APIs expose typed errors, redacted secrets/configuration, cancellation and finite deadlines. No upstream source is copied into own code. rsipstack internally uses unbounded transport/transaction channels and a String credential; its limits, parser behavior and secret-copy lifetime need further review/mitigation before production (tasks 2.3/4.1), not an implicit exception. G0 fixtures have a trusted disposable peer/network and container resource limits; that is not malicious-network acceptance. Do not install a tracing subscriber or serialize upstream request/credential/error/SDP objects in the fixture.

A successful registration slice does not check task 1.6: two-way PCMA/PCMU calls and independent-endpoint measurements remain mandatory. DTMF/hold/REFER/SRTP, complete-stack desktop/audio/IPC ELF, host/VM ACL/media and human exact-artifact acceptance remain blocking G0/release requirements. rustrtc and audio-codec are not adopted in this slice; the latter remains blocked for its missing complete notice. No full UI implementation or usable-release announcement follows from this experiment alone.
