# ADR 0005 — own G.711 primitives and isolated plain-RTP call proof

Date: 2026-10-12. Status: accepted for isolated G0 evaluation only. Baseline: `bfe9539`. Full G0, production-media and release approval remain pending.

## Decision and provenance

Add the project-owned `crates/media` library for allocation-free G.711 sample conversion and bounded RTP v2 packets. It has no normal dependencies, device access, networking or cryptography. The existing selected `sha2 0.11.1` (MIT OR Apache-2.0) is used only by exhaustive functional tests; it was already present in the reviewed registry inventory. Do not adopt the blocked `audio-codec` package, copy third-party codec source/tables, or introduce a native codec backend. `rustrtc` is not adopted by this slice.

The implementation uses arithmetic quantization, sign, segment and mantissa operations. Protocol references are [ITU-T G.711](https://www.itu.int/rec/T-REC-G.711-198811-I/en), [RFC 3551](https://www.rfc-editor.org/rfc/rfc3551.html) (8 kHz mono, static PCMU/PCMA payloads 0/8), and [RFC 3550](https://www.rfc-editor.org/rfc/rfc3550.html) (RTP packet structure). No reference implementation or standard text is embedded.

Independent functional hashes were generated with CPython 3.12.3's installed `audioop`, using all 65,536 signed i16 inputs and all 256 encoded octets per codec. `packaging/g711-reference-vectors.py` documents input order and byte order and prints only hashes. Rust tests use these four constants, not an upstream lookup table or recorded audio. This is an exhaustive comparison to that functional oracle, not independent ITU certification. [Python's documentation](https://docs.python.org/3.12/library/audioop.html) describes the conversion APIs; this deprecated module is a developer oracle only, never a build/runtime requirement. Host Python 3.13 cannot run this oracle. Its source is not copied into the project or product.

## Experiment boundary

`crates/telephony/src/g0_calls.rs` and its opt-in example use the experimental adapter from [ADR 0004](0004-experimental-sip-adapter.md). Two endpoints in **one process**, with separate signaling/media sockets and dialogs, register to a disposable Asterisk PBX, exchange different synthetic tones and verify remote rather than echoed local audio. The default Python peer is disabled for this overlay. Registration, INVITE/200/ACK, media, BYE/200, endpoint-wide termination observations and both unregistrations must succeed before reporting a completed call.

Only the fixed fictional UDP 1001/1002, TCP 1101/1102 and TLS **RTP-only** 1301/1302 pairs are admitted. TLS validates the explicit lab CA and hostname; it does **not** encrypt RTP. Mandatory-SRTP 1201/1202 accounts are rejected, not downgraded. Plaintext RTP is explicit and confined to the private, port-free Docker network. No personal account resolution, microphone, recording or shipping CLI control is installed.

Own SDP input is limited to 8 KiB, 128 lines and 512 bytes/line, one anchored G.711 audio stream and PBX ports 10000–10019. A call requires at least 240 sent and 200 received packets per endpoint, RMS 1000–10000 and remote-to-own tone power ratio at least 20; loss/late counts are reported, not required to be zero by the probe. Own RTP input is bounded to 1500 bytes, borrowed and checked for negotiated source, payload, 160-sample frames, stable SSRC and sequence/timestamp continuity. Fixed synthetic initial values deliberately exercise sender rollover; randomized session initialization remains a production requirement. The incoming queue is bounded to one; state observation is capped at 64 events. The example runs IPv4 only; IPv6 is untested and must not be inferred from generic socket types. A 30-second total operation deadline and owned-task cancellation bound each five-second call. Upstream unbounded parser/transaction channels and secret copies remain unresolved production gates, not waived by this fixture. Own call setup also explicitly clones a credential into `InviteOption` for authenticated INVITE handling; `OwnedRegistration` does not zeroize that extra dialog-lived String. The example converts serde-decoded Strings into `SecretString`, which can leave a reallocated original buffer uncleared. The example read/parse buffers can also leave earlier reallocated or serde scratch allocations uncleared; only the final read buffer is Zeroizing. All adapter-originated copies/read-parse buffers need elimination or verified lifetime/zeroization before production.

On successful completion the fixture verifies BYE and unregisters. Failure/cancellation drops owned tasks/sockets; it does not yet guarantee authenticated unregistration or remote BYE on every error path. Disposable PBX teardown is required; this is not the production shutdown contract. No hostile-network robustness is claimed.

## Evidence and remaining work

See the [synthetic-call receipt](../receipts/g0-rust-media-2026-10-12.md) for exact identities and executed results. Five-second synthetic calls are **not** five-minute human headset acceptance, a release artifact, separate-machine testing or full AUD-01. Resampling, jitter/impairment, RTCP, real devices, mute, DTMF, hold, transfer, SRTP/SDES, host/VM/NAT and the full desktop/IPC stack remain required. Tasks 1.6, 1.7, 1.8 and 5.1 retain their original criteria; no full UI or release is authorized by this ADR alone.
