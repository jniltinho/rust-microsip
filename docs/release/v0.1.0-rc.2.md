# rust-microsip 0.1.0-rc.2 (pre-release, not v0.1.0)

> **This is a release candidate for testing, not the v0.1.0 release.** The final release still needs the human and clean-VM gates listed in the [roadmap](https://github.com/jniltinho/rust-microsip/blob/main/docs/README.md#remaining-for-v010) and the owner's decision.

## Changes since 0.1.0-rc.1

- **MicroSIP-like interface**:
  - keypad with large left-aligned digits;
  - notebook tabs with the ▼ menu;
  - Logs-style call history: columns, direction icons, missed calls in red, double-click to call back, right-click menu;
  - contacts list and search at the bottom;
  - grouped Account and Settings panels;
  - a status bar with an **Online** icon.
- **Close to tray**: with a tray available, closing the window keeps the app in the tray. The tray menu redials the last five calls and has Quit. On Wayland the window is minimized instead.
- **Early media**: messages and ringback the PBX plays before the call is answered (a 180/183 response with SDP) are now heard. Before this release they were silent.
- **Local ringback**: while a call rings without early media, a ringback tone plays in the Brazilian cadence: 425 Hz, 1 s on, 4 s off.
- **Diagnostics**: `RUST_MICROSIP_TRACE=1` prints SIP status codes, the SDP shape and media counters to stderr. It never prints numbers, credentials or keys.
- **Audio devices**: on PipeWire/PulseAudio desktops the device list no longer offers raw ALSA PCMs, which do not work there. Choose the headset in the desktop's sound settings and keep "System default" in the app.
- **Dark theme** is now the default.
- **Wayland**: calls, incoming-call notifications and SIGTERM keep working while the window is covered or minimized.
- **Desktop entry**: the link handler entry names the real executable, so GNOME and KDE show the dock icon and `sip:`/`tel:` links open the app.
- **Windows (preview, not published in this release)**: the code builds for Windows, and the adapter tests pass on a Windows runner. The UI renders on a VM without a GPU.

## Requirements

glibc 2.39 or newer, `libasound.so.2` and, on X11, `libxkbcommon-x11`. The AppImage wraps the identical ELF.

## Known limitations

- No human two-way audio acceptance yet. There is no echo cancellation, so use a headset.
- One account and one active call at a time. No accepted NAT traversal (STUN/ICE).
- The interface follows MicroSIP but is not identical: there is no R key, no AA/CONF/REC toggles, and no Export/Import menu entries yet. The call log shows ages ("35 min") rather than dates. See [refine-native-ui](https://github.com/jniltinho/rust-microsip/blob/main/openspec/changes/refine-native-ui/tasks.md).
- Checksums give integrity, not authorship. The artifacts are not signed.
