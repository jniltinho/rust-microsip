# rust-microsip 0.1.0-rc.1 (pre-release, not v0.1.0)

> **This is a release candidate for testing, not the v0.1.0 release.** The final release still needs the human and clean-VM gates listed in the [roadmap](https://github.com/jniltinho/rust-microsip/blob/main/docs/README.md#remaining-for-v010): two-way audio with headsets, calls from desktop VMs through the lab, NAT/STUN, the AppImage runtime licence decision, and the owner's decision. Do not use it with production accounts until then.

A native Linux (x86_64, glibc) SIP softphone in Rust with a compact, MicroSIP-inspired egui window.

## What is in it

The [documentation index](https://github.com/jniltinho/rust-microsip/blob/main/docs/README.md) lists every area with its receipt. In short:

- **Calls**: UDP/TCP/TLS registration; PCMU/PCMA calls; DTMF (RFC 4733); hold and resume; mute; blind transfer; DND.
- **Media security**: SDES-SRTP/SRTCP with downgrade refusal.
- **Window**: Phone, Calls and Contacts tabs with SQLite history and contacts; CSV import; themes; accessibility labels.
- **Desktop**:
  - incoming-call notifications with Answer/Reject;
  - tray icon with Show/Quit, and the app icon on the window;
  - opt-in `sip:`/`tel:` handler that names the real executable;
  - single instance and graceful SIGTERM.
- **Configuration**: CLI, environment, `.env`, TOML and the SQLite store with provenance (`--doctor`, `config validate/export/import`); the password can be kept in the Secret Service keyring.
- **Local control for agents** (preview): `rust-microsip` CLI and `mcp --stdio` over a kernel-authenticated socket. Every change waits for **Allow** in the window unless a person issued a scoped, revocable grant. `rust-microsip service` runs without a window from a single-use bootstrap.

Checked on:
- the disposable Asterisk lab suite (9/9 scenarios on the release commit's code);
- clean desktop VMs: Ubuntu 24.04 (KDE X11, GNOME Wayland), Ubuntu 26.04 (GNOME Wayland), Fedora 44 (KDE Plasma 6 Wayland) and Arch Linux (Xfce X11). See the [desktop VM receipt](https://github.com/jniltinho/rust-microsip/blob/main/docs/receipts/desktop-vms-2026-10-13.md).

## Requirements

glibc 2.39 or newer, `libasound.so.2` (ALSA) and, on X11, `libxkbcommon-x11`. Standard GNOME and KDE desktops have these; on a minimal Xfce install, add `libxkbcommon-x11`. The AppImage wraps the identical ELF and runs without `libfuse2`.

## Known limitations

- No human two-way audio acceptance yet. There is no echo cancellation, so use a headset.
- One account and one active call at a time. No video, chat, presence, recording or conference.
- No accepted NAT traversal (STUN/ICE).
- On Wayland, a covered window answers control requests and tray "Show" only after it is shown again. Calls, notifications and SIGTERM keep working.
- Wayland docks show the app icon only after the link handler entry is installed (Settings).
- Checksums give integrity, not authorship. The artifacts are not signed.
