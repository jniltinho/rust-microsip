# rust-microsip 0.1.0-rc.3 (pre-release, not v0.1.0)

> **This is a release candidate for testing, not the v0.1.0 release.** The final release still needs the human and clean-VM gates listed in the [roadmap](https://github.com/jniltinho/rust-microsip/blob/main/docs/README.md#remaining-for-v010) and the owner's decision.

## Changes since 0.1.0-rc.2

- **Windows preview packages**:
  - `rust-microsip-0.1.0-rc.3-x86_64.msi`: a per-user installer that needs no administrator rights. It installs to `%LOCALAPPDATA%\Programs\rust-microsip` and adds a Start Menu shortcut. A newer version replaces an older one. Uninstalling keeps your settings in `%APPDATA%\rust-microsip`, your call history in `%LOCALAPPDATA%\rust-microsip` and the passwords in Credential Manager.
  - `rust-microsip-0.1.0-rc.3-windows-x86_64.zip`: a portable copy. Unzip it anywhere and run `rust-microsip.exe`.
  - Both contain `rust-microsip.exe` (the app), `rust-microsip-cli.exe` (CLI and MCP) and `THIRD-PARTY-NOTICES.txt`.
- Windows renders through DX12 only and falls back to WARP on machines without a GPU.

## Windows preview: what is and is not tested

- **Tested in CI on Windows Server 2022**:
  - the platform adapter: named pipes, Credential Manager, owner-only files, the tray, and the fallback when toasts are unavailable;
  - the unit and integration tests;
  - the MSI install, upgrade and uninstall.
- **Tested on a Windows VM without a GPU**: the window opens.
- **Not tested on Windows yet**: calls and audio.

The Windows packages are **not signed**, so Windows SmartScreen may show "Windows protected your PC". Before you choose "More info → Run anyway", check the download against `SHA256SUMS`:

```powershell
Get-FileHash .\rust-microsip-0.1.0-rc.3-x86_64.msi -Algorithm SHA256
```

## Requirements

- **Linux**: glibc 2.39 or newer, `libasound.so.2` and, on X11, `libxkbcommon-x11`. The AppImage wraps the identical ELF.
- **Windows**: Windows 10 1809 or newer, or Windows 11, x86_64.

## Known limitations

- No human two-way audio acceptance yet. There is no echo cancellation, so use a headset.
- One account and one active call at a time. No accepted NAT traversal (STUN/ICE).
- The interface follows MicroSIP but is not identical: there is no R key, no AA/CONF/REC toggles, and no Export/Import menu entries yet. The call log shows ages ("35 min") rather than dates.
- On Windows, toasts can only work through the Start Menu shortcut the MSI creates; they have not been tried on a desktop yet. The portable zip shows no toasts.
- Checksums give integrity, not authorship. No artifact is signed.

## Verify a download

```sh
sha256sum --check --strict SHA256SUMS
./rust-microsip-0.1.0-rc.3-x86_64 --version
```
